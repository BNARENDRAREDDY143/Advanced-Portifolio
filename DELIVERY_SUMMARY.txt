🎓 CUSTOMIZATION GUIDE
================================================================================

Easy Changes (No coding needed):

1. Change Colors
   Edit: src/AppAdvanced.css
   Change: CSS variables (--primary-color, etc.)

2. Update Content
   Edit: Components/Pages/*.jsx
   Update: Text, images, links

3. Modify Social Links
   Edit: Components/Pages/Contact.jsx
   Add: Your contact information

4. Change Animations Speed
   Edit: CSS animation files
   Change: Duration value (e.g., 6s → 3s)

5. Add/Remove Orbs
   Edit: Components/3D/FloatingOrbs.jsx
   Change: Array.from({ length: 5 }, ...)

6. Adjust Parallax Intensity
   Edit: src/AppAdvanced.jsx
   Change: scrollY * 0.5 → 0.3 (subtle) or 0.8 (dramatic)

All changes are straightforward and well-documented!
